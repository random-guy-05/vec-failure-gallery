# VEC Failure Mode Gallery

A zero-install visual atlas connecting common generative/submission failures to the official VEC scoring questions.

## Included failure modes

1. Population collapse
2. Wrong cell-state mixture
3. Reversed gene response
4. Scrambled co-expression
5. Spatial line collapse
6. Uniform tissue-scale error
7. Local neighborhood scrambling
8. Raw-count expression
9. Gene-order mismatch

Open `index.html` for the browser gallery, or use `VEC_FAILURE_MODE_GALLERY.pdf`. Every plate is also available as editable SVG and high-resolution PNG.

Metric signatures are intentionally labeled as **likely/qualitative**: multiple failures can affect multiple metrics, and only the official scorer determines the actual score. No Challenge targets or restricted data are included.
